Sinusoidal Pulse Width Modulation (SPWM)

The foundation of modern motor control - generating smooth AC waveforms from DC power

🎯 What is SPWM?

Sinusoidal Pulse Width Modulation (SPWM) is a technique that converts DC bus voltage into AC voltage waveforms by comparing a sinusoidal reference signal with a high-frequency triangular carrier wave. This creates a PWM signal whose average value follows the sinusoidal reference, enabling smooth motor control.

🔄 Smooth Operation

Generates sinusoidal currents for reduced torque ripple and acoustic noise

Optimizes DC bus utilization up to 78.5% of available voltage

📐 Mathematical Foundation

SPWM Generation Principle: The PWM signal is generated by comparing the sinusoidal reference vref(t) = Vm · sin(ωt) with the triangular carrier vcarrier(t) = VΔ · (2 fc t - floor(2 fc t + 1)). The inverter output is ON when vref is above vcarrier, and OFF otherwise.

Modulation index m is the ratio of the sine amplitude to the carrier amplitude: m = Vm / VΔ. The peak output voltage becomes Vout,peak = m · (VDC / 2), and the RMS output is Vout,RMS = (m · VDC) / √2. DC bus utilization is therefore η = (Vout,peak / VDC) × 100% = m/2 × 100%.

For three-phase systems, the line voltages are differences between phase voltages: VAB = VAO - VBO, VBC = VBO - VCO, and VCA = VCO - VAO. Here VAO, VBO, VCO are the phase-to-neutral voltages.

🔄 Types of SPWM

📊 Single-Phase SPWM

Basic implementation for single-phase applications like UPS systems and small drives.

Advantages:
  • Simple implementation
  • Low computational requirements
  • Suitable for low-power applications
Limitations:
  • No neutral point
  • Higher THD compared to three-phase
  • Limited to single-phase loads

🔺 Three-Phase SPWM

Standard for three-phase motor drives with 120° phase shift between references.

Advantages:
  • Balanced three-phase output
  • Lower THD than single-phase
  • Optimal for motor applications
Limitations:
  • Requires three PWM channels
  • More complex synchronization
  • Higher component count

🎯 Bipolar vs Unipolar SPWM

Bipolar uses single reference, unipolar uses two complementary references.

Bipolar Advantages:
  • Simpler implementation
  • Lower switching losses
  • Better for high frequencies
Unipolar Advantages:
  • Lower THD
  • Higher DC bus utilization
  • Better harmonic performance

📈 Total Harmonic Distortion (THD)

THD measures the harmonic distortion in the inverter output. SPWM keeps the desired fundamental clean while shifting high-frequency switching harmonics away from the motor band.

THD is the square root of the sum of the squared harmonic voltages divided by the squared fundamental voltage, expressed as a percentage: THD = √[(V2² + V3² + V4² + ...)/V1²] × 100%.

VAO (Pole Voltage)

Voltage from phase A pole to the inverter midpoint or reference point.

VAB (Line Voltage)

Difference between phase A and phase B outputs, which is the actual terminal voltage seen by the motor.

VPhase

Phase-to-neutral waveform produced by SPWM. The fundamental envelope is sinusoidal while the switching waveform is pulse-modulated.

Key Insights

  • SPWM is the baseline for three-phase motor drives, with smooth phase voltage output.
  • Line voltage is the difference between phase poles, so line-to-line fundamentals are critical.
  • Pole voltages are directly generated by the switching legs and form the phase waveforms.

🔧 Practical Implementation

Microcontroller Implementation

// STM32 SPWM Implementation Example
#define CARRIER_FREQ 5000
#define FUNDAMENTAL_FREQ 50
#define MODULATION_INDEX 0.8

void SPWM_Init() {
    // Configure Timer for carrier generation
    TIM1->ARR = SystemCoreClock / (2 * CARRIER_FREQ);
    TIM1->CCR1 = TIM1->ARR / 2;  // 50% duty for triangle

    // Enable PWM outputs
    TIM1->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E | TIM_CCER_CC3E;
}

void SPWM_Update(float m, float theta) {
    // Calculate reference voltages for three phases
    float v_ref_a = m * sin(theta);
    float v_ref_b = m * sin(theta - 2*M_PI/3);
    float v_ref_c = m * sin(theta + 2*M_PI/3);

    // Update PWM duty cycles
    TIM1->CCR1 = (uint16_t)((v_ref_a + 1) * TIM1->ARR / 2);
    TIM1->CCR2 = (uint16_t)((v_ref_b + 1) * TIM1->ARR / 2);
    TIM1->CCR3 = (uint16_t)((v_ref_c + 1) * TIM1->ARR / 2);
}

Key Implementation Considerations

⏱️ Timing Requirements

  • PWM update rate: 10-20 kHz
  • ADC sampling: Synchronized with PWM
  • Phase shift: 120° for three-phase
  • Dead time: 1-2 μs for safety

🛡️ Safety Features

  • Dead time insertion
  • Overcurrent protection
  • DC bus voltage monitoring
  • Thermal shutdown

🎛️ Control Parameters

  • Modulation index: 0-1.27 (with overmod)
  • Carrier ratio: 20-100
  • Phase sequence: ABC or ACB
  • Voltage boost: For low speeds
